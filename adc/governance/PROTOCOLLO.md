# Protocollo di revisione indipendente e conservazione

I record sono **in attesa di revisione indipendente**. La ricognizione tecnica interna non costituisce approvazione scientifica.

Ogni revisore deve essere identificato, dichiarare eventuali conflitti di interesse, consultare la fonte primaria, registrare pagina e citazione puntuale, formulare una decisione datata (approvato / richiesta correzione / respinto), firmarla e conservarne evidenza. Il curatore non puo assegnare un parere esterno a se stesso.

Esportazioni: JSON, CSV e XML Dublin Core semplificato. Questi file consentono importazione/scambio e **non implementano un endpoint OAI-PMH**. Non attribuire DOI o identificatori archivistici persistenti inesistenti.

Conservazione: due copie indipendenti almeno, una offline, verifica SHA-256 periodica e prova documentata di ripristino. Il repository Git pubblico non sostituisce il backup dei documenti originali privati. Verificare licenze, accessi e dati personali prima di ogni pubblicazione.

Registrare ogni intervento nel registro decisionale senza cancellare le versioni precedenti.
