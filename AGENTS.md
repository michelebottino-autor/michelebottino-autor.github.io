# Istruzioni per agenti — Sito autore

Prima di qualsiasi modifica a contenuti visibili leggere **.github/EDITORIAL_POLICY.md**.

- Non pubblicare note tecniche né informazioni sul processo di sviluppo nelle pagine web.
- Non nascondere o inventare fatti, qualifiche, fonti, condizioni reali o diritti.
- Separare artefatti tecnici e contenuti editoriali. Mantenere log e verbali nei documenti di lavoro, non collegarli dalla UI.
- Aggiornare anche i generatori delle pagine, non solo l'HTML generato.
- Eseguire il controllo **`node .github/scripts/verify-public-editorial.js`** e il collaudo dei collegamenti prima della pubblicazione.
- Non eseguire commit/push di file privati, credenziali, scansioni originali o backup senza richiesta esplicita.
